# 📖 Overview

AI YouTube Video Analyzer is an intelligent AI-powered application that analyzes YouTube videos and generates structured reports in just a few seconds.

Instead of spending time watching lengthy videos, simply paste the video URL and let AI extract the most valuable information.

The application uses **Agno AI Agent Framework**, **Groq LLM**, and **Streamlit** to provide fast, interactive, and high-quality video analysis.

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/PrinceYadav001/Youtube_Video_Analyzer_Agent.git

cd Youtube_Video_Analyzer_Agent
```

---

## 2️⃣ Create Virtual Environment

### Windows

```bash
python -m venv venv

venv\Scripts\activate
```

### Linux / macOS

```bash
python3 -m venv venv

source venv/bin/activate
```

---

## 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 4️⃣ Configure Environment Variables

Create a `.env` file:

```env
GROQ_API_KEY=your_groq_api_key
```

---

## 5️⃣ Run the Application

```bash
streamlit run ui.py
```

The application will launch automatically in your browser.
